❔ Aam Sawalat (FAQ)

Kya meri audio kahin upload hoti hai?

Browser walay tareeqay mein bilkul nahi — gana aap ke device se bahar nahi jata. Server walay tareeqay mein audio sirf Hugging Face ke free server ko bheji jati hai taake wahan lyrics ban saken; hamari website par kuch save nahi hota.

Urdu / Saraiki ganon ke lyrics milenge?

Ji, Urdu, Hindi, Punjabi, Bengali, Arabic aur English samait bohat si zabanon ke lyrics milte hain. Saraiki aksar Urdu ya Punjabi script mein likhi aati hai, kyunke models unhi scripton par zyada trained hain.

Lyrics mein ghaltiyan kyun aati hain?

Tez music, echo ya shor awaaz ko daba deta hai. Sirf awaaz wali saaf recording par sab se acha result aata hai — vocals alag karne ke liye hamara free Demucs notebook bhi hai: SurGeet-Demucs-Separation.ipynb

Server busy / error aaye to kya karoon?

Free servers par rush hota rehta hai. Thori dair baad dobara koshish karein, ya upar se Browser wala tareeqa chunein — wo kisi server ka mohtaj nahi.

Bara (lamba) gana ho to?

Chalega — Browser tareeqay mein gana 30-second ke hisson mein bant kar aik ke baad aik likha jata hai. Server tareeqay mein lamba gana zyada waqt lega.
